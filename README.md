## The Odin Project - Admin Panel Project
### Summary:
I have previously worked a lot with HTML and CSS, I have built many websites, and thought I had a really good grasp on CSS grid, Flexbox, and more. However, this project has definetly humbled me a bit with CSS Grid and using nested grids. 
### Features:
- left side navigation panel 
- an upper navigation panel complete with a search bar, current user info, and user navigation
- a 6 project grid, with icons for the user 
- an announcements section
- a trending section.
### Methods: 
- HTML
- CSS
- Claude Code for guided learning through difficult concepts, not writing code.
- The Odin Project for notes and assistance
- MDN for notes and assistance
### Process:
1. HTML Creation
2. Began with the left navigation in CSS
3. Moved to the top navigation section working left to right, top to bottom.
4. Moved to the projects section working top to bottom.
5. Finished with the announcements and trending sections.
### Issues: 
I found some areas with grid to be a bit complex. This is not the first time I have worked with nested grid layout but it is early in those areas for me.
